# Ultimate Ores Adventure — Forge 1.20.1

A source project designed to be uploaded to GitHub and built into a Minecraft Forge 1.20.1 `.jar`.

## Materials
- Titanium
- Brass
- Bronze
- Steel
- Invar
- Electrum
- Astral (original high-tier material)
- Voidsteel (original high-tier material)
- Celestium (original high-tier material)

## Planned adventure progression
1. Overworld: common alloy ores and early armor.
2. Astral Realm: Astral ore, rare structures and a guardian boss.
3. Void Realm: Voidsteel ore, dangerous mobs and a stronger boss.
4. Celestial Realm: Celestium ore, endgame loot and the final boss.

## Boss loot concepts
- Astral Guardian → Astral Core
- Void Warden → Void Heart
- Celestial Sovereign → Celestial Shard

The current source contains the registry foundation and GitHub build workflow. More gameplay systems can be added on top of this base.
